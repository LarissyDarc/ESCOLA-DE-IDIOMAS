## 🚀 Plugins React

O projeto pode utilizar uma das seguintes opções oficiais:

- `@vitejs/plugin-react` — utiliza Oxc.
- `@vitejs/plugin-react-swc` — utiliza SWC.

## ▶️ Como Executar

Requisito: Node.js instalado.

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173` no navegador.
